A typed control plane for LLM traffic

Switchyard sits between LLM clients and model backends. It gives clients stable OpenAI- and Anthropic-compatible interfaces while it selects a target, translates the wire format, streams the result, and records what happened.

The shortest mental model is:

client contract + normalized conversation + routing policy + target transport

Those four concerns are deliberately separate. A caller can keep its API, a router can reason over common types, and a target can use a different provider protocol.

Switchyard turns a model name into a governed, observable routing policy while preserving the client's native API.
